# 🌐 Bhargav Portfolio

A modern, responsive personal portfolio website built to showcase my backend engineering experience, projects, skills, and contact details.

## ✨ Overview

This project is a single-page portfolio website designed with a clean, dark-themed UI and smooth scrolling interactions. It highlights:

- 🧠 Backend engineering experience
- 🏗️ Project work and system design thinking
- 🛠️ Tech stack and tools used
- 📄 Resume download
- 📫 Contact and social links

## 🧩 What’s Included

- Professional hero section with introduction
- Experience timeline
- Project showcase cards
- System architecture / workflow visualization
- Skills and learning sections
- Light/dark theme toggle
- Contact information and social media links

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive web design

## 📁 Project Structure

```bash
bhargav-portfolio/
├── index.html        # Main portfolio page
├── README.md         # Project documentation
├── resume.pdf        # Downloadable resume
└── .gitignore        # Git ignore config (if present)
```

## 🚀 How to Run Locally

Since this is a static website, you can run it in a few easy steps:

1. Open the project folder.
2. Start a local server:

```bash
python -m http.server 8000
```

3. Visit:

```bash
http://localhost:8000
```

You can also simply open `index.html` directly in a browser if preferred.

## 📝 Notes

- The portfolio is fully editable in `index.html`.
- You can replace the resume file with your updated version.
- The site is designed for GitHub Pages deployment as well.
